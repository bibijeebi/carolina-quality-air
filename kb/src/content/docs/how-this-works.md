The Shop Book is the source of truth for how CQA works: gear, chemicals, procedures, and jobs. [DuctStudy](/learning/) is the training layer. Drills and scenarios get built from these pages, so fixing a page here fixes the drill too.

## Rules for every page

1. **Specs come from the manufacturer.** Manuals, labels, SDS sheets, spec pages. Every number has a source link at the bottom.
2. **Shop practice is labeled as shop practice.** "We do it this way" is fine. It just isn't dressed up as a spec.
3. **Unsure means marked.** If a fact isn't confirmed, it says _(unconfirmed)_.
4. **The label wins.** For any chemical, the product label beats this book.

## Machine page template

- **Fact strip:** job, key specs, what kills it
- **How it works** (one diagram when it helps)
- **Setup**, numbered
- **Maintenance**, with intervals
- **Symptom to fix** table
- **Safety**
- **Sources**

## Chemical page template

- **Fact strip:** EPA reg. no., mix, how much, apply with, PPE
- **When to use it / when not to**
- **Application**, from the label
- **Sources:** label, SDS, product page

## Adding or fixing something

Tell Benny what's wrong or missing: a text, a photo of the nameplate or label, or a voice memo of how you actually use it. The page gets updated, checked against the manufacturer, and republished.
